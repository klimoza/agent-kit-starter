# agent-kit — вход сопровождающего

Общие правила агентов для всех проектов владельца, плагин Claude Code и шаблоны, с
которых начинается среда: репозиторий памяти, проект, служба на сервере. Этот
репозиторий сопровождает выпуски правил; он не рабочий проект.

## Что читать

1. Сверить выпуск ниже, затем его [CORE](releases/v1.1/CORE.md) и этот файл.
2. [README](README.md) — что где лежит; [SETUP](SETUP.md) — как из этого собирается среда;
   [CHANGELOG](CHANGELOG.md) — выпуски; [LESSONS](LESSONS.md) — уроки, из которых растут правила.
3. Для плагина: затрагиваемый навык или хук в `plugin/` и его скрипт.

## Как меняются правила

1. Предложение с основанием: что не сработало, в каком проекте, какое наблюдение —
   записью в [LESSONS](LESSONS.md).
2. Решение владельца — для всего, что меняет обязанности агентов в проектах. Опечатки и
   пояснения без изменения смысла решения не требуют.
3. Новый выпуск: `scripts/release.sh new vX.Y`, правка `releases/vX.Y/`,
   `scripts/release.sh seal vX.Y`, запись с хешем в CHANGELOG, обновление блока ниже.
4. Проекты переходят на выпуск явно — навыком `/kit-upgrade`, по слову владельца.

## Границы

- Запечатанный выпуск (`releases/vX.Y/` с `MANIFEST.sha256`) не правится: изменения идут
  новым выпуском. Проект на новый выпуск молча не переводится.
- Шаблоны в `templates/` и плагин правятся без выпуска; после правки скриптов —
  `bash -n` на них и `scripts/release.sh check`.
- Личных данных, секретов и фактов конкретных проектов здесь нет: в kit живут только
  правила и шаблоны.
- Проверенные свои изменения коммитятся и пушатся в `main`, без force-push.
