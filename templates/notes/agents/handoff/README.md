# Передача работы между сессиями

Один файл на работу: `agents/handoff/<тема-латиницей>.md`. Заводит агент, начавший
работу длиннее одного хода; обновляет на каждом существенном шаге. Правило —
`systems.md` §5. Закрытая работа: `status: done`; файл остаётся до конца месяца, потом
удаляется (итог уже в журнале).

```markdown
# <тема>

- owner: какая сессия ведёт работу сейчас
- where: тред или чат, где она идёт
- status: active | waiting-human | done
- updated: ГГГГ-ММ-ДД ЧЧ:ММ
- ask: что попросил владелец — цитатой
- repos: репозитории, ветки, PR

## Сделано
## Дальше
Первый конкретный шаг для того, кто продолжит.
## Открытые вопросы
```
