# agent-kit-starter

Шаблон проекта, в котором работают ИИ-агенты (Claude Code, Codex и другие). Агент каждый
раз приходит без памяти, поэтому всё, что ему нужно знать, лежит в самом репозитории:
правила поведения — в `agent-kit/`, состояние проекта — в `docs/`, вход — в `AGENTS.md`.

## Как начать

1. На GitHub нажми **Use this template → Create a new repository** (или просто скопируй
   эти файлы в свой проект).
2. Заполни всё в угловых скобках `<…>` в `AGENTS.md` и `docs/*.md`. Можно поручить это
   агенту: «заполни шаблон, проект — про …».
3. Замени этот README описанием своего проекта.
4. Открой папку в Claude Code или Codex и дай первую задачу. Агент начнёт с `AGENTS.md`,
   а после работы обновит `docs/STATUS.md`.

## Что где лежит

```
AGENTS.md            вход для агента: что за проект, что читать, ограничения
CLAUDE.md            одна строка @AGENTS.md (Claude читает CLAUDE.md, Codex — AGENTS.md)
agent-kit/
  CORE.md            ядро: что агент делает сам, на что спрашивает разрешение, Git, секреты
  PROJECT.md         какие файлы бывают в проекте и как в них писать
  STATUS.md          как писать сводку проекта — пять полей на десять секунд чтения
  LESSONS.md         уроки о поведении агентов, общие для всех твоих проектов
  modules/           по желанию: clusters (Slurm, GPU), research-experiments (эксперименты)
docs/
  STATUS.md          ## Project summary — где мы, что дальше, что нужно от тебя
  DECISIONS.md       твои решения и открытые вопросы к тебе
  LESSONS.md         уроки проекта: что не сработало и какой из этого вывод
  HISTORY.md         хронология, только дописывается
```

Остальные файлы (`DIRECTION`, `RULES`, `PROVENANCE`, `OPERATIONS`, `NAMES`, отчёты)
агент заводит, когда в проекте появляется то, что в них живёт, — по `agent-kit/PROJECT.md`.

Модули подключаются в `AGENTS.md`: впиши их в `modules:` и раскомментируй строки в
таблице «Что читать». Ненужные можно удалить из `agent-kit/modules/`.

## Под себя

- Правила написаны от лица «владельца» — это ты. Сводки для владельца по-русски
  (`agent-kit/CORE.md`, «Язык»); хочешь другой язык — поменяй там.
- Правила в `agent-kit/` — твои, их можно менять. Если проектов несколько, держи одну
  эталонную копию `agent-kit/` и переноси изменения в проекты явно.

## Почему так

- **Память — в репозитории, а не в агенте.** Память конкретного приложения видит только
  оно; файл в Git видят все агенты и ты сам.
- **Разрешение — словами владельца.** Молчание, зелёные тесты и «ты же вчера разрешил» —
  не согласие на публикацию, деплой или новые ресурсы.
- **Одно место для каждого факта.** Статус ссылается на решения и уроки, а не пересказывает
  их: две копии быстро расходятся.
